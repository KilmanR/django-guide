Часть 5: Тестирование

Тесты защищают код: находим ошибки до пользователя.

Простой тест модели

В polls/tests.py:
```python
from django.test import TestCase
from .models import Question

class QuestionModelTests(TestCase):
def test_was_published_recently_with_future(self):
# Вопрос из будущего не должен считаться недавним.
import datetime
from django.utils import timezone
future_question = Question(pub_date=timezone.now() + datetime.timedelta(days=30))
self.assertIs(future_question.was_published_recently(), False)
```

Тест view

def test_no_questions(self):
    response = self.client.get("/polls/")
    self.assertContains(response, "Нет голосований.")

Запуск

python manage.py test polls

Каждый тест создаёт свою тестовую БД (не трогает рабочую).

Принцип

Тестируйте поведение, которое пользователь увидит: страницы возвращают 200,
содержат нужный текст, редиректы работают.
