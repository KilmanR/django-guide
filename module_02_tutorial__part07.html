Часть 7: Кастомизация админки

Улучшаем отображение вопроса

polls/admin.py:

from django.contrib import admin
from .models import Choice, Question

class ChoiceInline(admin.TabularInline):
    model = Choice
    extra = 3

class QuestionAdmin(admin.ModelAdmin):
    fieldsets = [
        (None, {"fields": ["question_text"]}),
        ("Данные", {"fields": ["pub_date"], "classes": ["collapse"]}),
    ]
    inlines = [ChoiceInline]
    list_display = ("question_text", "pub_date", "was_published_recently")

admin.site.register(Question, QuestionAdmin)

Добавим метод was_published_recently в модель

В polls/models.py:

import datetime
from django.utils import timezone

def was_published_recently(self):
    return self.pub_date >= timezone.now() - datetime.timedelta(days=1)

Фильтры и поиск

В QuestionAdmin добавьте:

list_filter = ["pub_date"]
search_fields = ["question_text"]

Теперь админка удобная: карточки, инлайн-варианты, фильтры, поиск.
