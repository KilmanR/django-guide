Шпаргалка команд Django

Обновлено 2026-09-03. Версия Django: 5.x (актуальная стабильная).

Создание и запуск проекта

1. Создать проект

django-admin startproject mysite
cd mysite

2. Запустить dev-сервер

python manage.py runserver
# по умолчанию http://127.0.0.1:8000
# укажите порт: python manage.py runserver 8080

3. Создать приложение

python manage.py startapp polls

Приложение нужно «зарегистрировать» в settings.py → INSTALLED_APPS.

Команды manage.py (часто используемые)

КомандаЧто делает

Миграции

# 1. Создать миграции после изменения models.py
python manage.py makemigrations polls

# 2. Показать SQL (не применяя)
python manage.py sqlmigrate polls 0001

# 3. Применить
python manage.py migrate

Работа с БД в shell

python manage.py shell
from polls.models import Question, Choice
# создать
q = Question(question_text="Как дела?")
q.save()
# выборка
Question.objects.all()
Question.objects.get(pk=1)
# связанные записи
q.choice_set.create(choice_text="Хорошо", votes=0)

Админка

python manage.py createsuperuser
# затем http://127.0.0.1:8000/admin/

Полезно

  • Показать все команды: python manage.py help
  • Показать помощь по команде: python manage.py help cmd
  • Django-расширения (отладка): pip install django-extensions
