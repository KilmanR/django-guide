Management-команды

Свои команды ./manage.py ... — для фоновых задач, чистки, импорта и т.п.

Структура

app/
├── management/
│   ├── __init__.py
│   └── commands/
│       ├── __init__.py
│       └── clean_old.py       ★ имя файла = имя команды
├── ... (модели, views)

Команда регистрируется автоматически при наличии management/commands в приложении.

Пример команды

from django.core.management.base import BaseCommand, CommandError
from .models import Session

class Command(BaseCommand):
    help = 'Удаляет старые сессии'

    def handle(self, *args, **options):
        count, _ = Session.objects.filter(expired__lt=...).delete()
        self.stdout.write(self.style.SUCCESS(f'Удалено сессий: {count}'))

Аргументы командной строки (add_arguments)

class Command(BaseCommand):
    help = 'Импортирует данные пользователей'

    def add_arguments(self, parser):
        parser.add_argument('source', type=str)                # позиционный
        parser.add_argument('--limit', type=int, default=100)  # опциональный
        parser.add_argument('--dry-run', action='store_true')  # флаг

    def handle(self, *args, **options):
        src = options['source']
        limit = options['limit']
        dry = options['dry_run']
        if dry:
            self.stdout.write('Режим проверки (без записи)')

Запуск:

python manage.py import_users data.csv --limit 50 --dry-run

Вывод в консоль и ошибки

self.stdout.write('обычное сообщение')            # в stdout
self.stderr.write('в stderr')                     # в stderr
self.stdout.write(self.style.ERROR('красно'))     # стили
self.stdout.write(self.style.SUCCESS('зелено'))
raise CommandError('что-то не так — команда выдаст ошибку')   # abort

Опции по умолчанию (уже есть у BaseCommand)

  • --verbosity {0,1,2,3} — уровень детализации.
  • --settings, --pythonpath, --no-color.
  • np: чтобы выключить input() не забывайте: options['interactive'].

Обращение к БД внутри handle

handle работает в контексте Django — можно делать ORM-запросы и пользоваться
get(), filter(). Для транзакций:

from django.db import transaction

with transaction.atomic():
    for item in items:
        Item.objects.create(**item)

Тестирование команды

from django.core.management import call_command
from django.test import TestCase

class CleanCommandTest(TestCase):
    def test_command(self):
        call_command('clean_old', '--dry-run')   # тип аргументов как в CLI
        self.assertEqual(Session.objects.count(), 0)

Проверка вывода — self.assertIn над out/err через StringIO:

import io
out = io.StringIO()
call_command('clean_old', stdout=out)
self.assertIn('Удалено', out.getvalue())

Cron / фоновый запуск

# каждую ночь в 2:30 — crontab
30 2 * * * cd /home/user/proj && venv/bin/python manage.py clean_old >> /var/log/myapp.log 2>&1

Что нельзя

  • Не писать кириллические имена команд (будут проблемы с менеджером файлов на Windows).
  • Не вызывать сеть в __init__ команды.
