Интернационализация (i18n / l10n)

i18n — перевод строк приложения, l10n — локализация форматов (даты, числа).
Всё строится на gettext + словари переводов .po/.mo.

Настройки settings.py

USE_I18N = True                    # вкл. систему переводов
USE_L10N = True                    # вкл. локализацию форматов (Django < 4)
LANGUAGE_CODE = 'ru-RU'            # язык по умолчанию
LANGUAGES = [
    ('ru', _('Русский')),
    ('en', _('English')),
]
LOCALE_PATHS = [os.path.join(BASE_DIR, 'locale')]   # где лежат переводы
TIME_ZONE = 'Europe/Moscow'        # часовой пояс
USE_TZ = True

Перевод в Python-коде

from django.utils.translation import gettext as _

def index(request):
    msg = _('Привет, мир!')            # вернёт перевод для текущего языка
    return HttpResponse(msg)

# с плейсхолдерами и числовыми множественными формами:
from django.utils.translation import ngettext
n = len(items)
text = ngettext('у вас %(count)d файл', 'у вас %(count)d файла', n) % {'count': n}

# ленивый вариант для моделей/forms (ставится один раз, переводится при выводе):
from django.utils.translation import gettext_lazy as _
class Article(models.Model):
    title = models.CharField(_('заголовок'), max_length=200)

# с контекстом (два одинаковых слова в разном контексте):
from django.utils.translation import pgettext
msg = pgettext('month name', 'May')

Перевод в шаблонах

{% load i18n %}
<title>{% trans "Главная" %}</title>

<p>{% trans "Привет, %(name)s!" %}</p>   <!-- без аргументов -->

{% blocktrans with name=user.username count n=items|length %}
    У вас {{ n }} файл от {{ name }}
{% plural %}
    У вас {{ n }} файла от {{ name }}
{% endblocktrans %}

Работа с файлами переводов

cd ~/myproject
python manage.py makemessages -l ru        # создать/обновить locale/ru/LC_MESSAGES/django.po
# (для шаблонов требуется gettext; опц. --extension=html,py)
# отредактировать django.po: msgstr «перевод»
python manage.py compilemessages            # собрать .mo из .po

В .po после генерации нужно дописать переводы, потом compilemessages.
msgid — исходная строка, msgstr — перевод.

Переключение языка из запроса

MIDDLEWARE = [ ... ,
    'django.middleware.locale.LocaleMiddleware',   # читает Accept-Language и cookie
    ... ]
  • язык берётся из заголовка Accept-Language, формы set_language или cookie django_language.
  • для «красивых» URL с префиксом языка:
# urls.py
from django.conf.urls.i18n import i18n_patterns

urlpatterns += i18n_patterns(
    path('admin/', admin.site.urls),
    path('', include('myapp.urls')),
)
  • Django сам может определить язык и подставить его; LANGUAGES ограничивает список.

Локализация форматов

  • фортеры localize на значениях /django, дат и чисел при USE_L10N=True.
  • конвертация в шаблоне: {{ value|localize }}, отключение — {{ value|unlocalize }}.
  • отключение локализации для одного значения — декоратор @unlocalize или фильтр.

check для i18n

python manage.py check          # консистентность локали и настроек

Ошибки вроде E103 подскажут проблемные настройки. После каждого изменения .po —
compilemessages, иначе будут видны только msgid-ы.
