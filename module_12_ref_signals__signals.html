Сигналы (Signals)

Сигналы — «уведомления» о происходящих событиях. Позволяют выполнить свой
код при сохранении модели, логине, запуске миграций и т.п., не меняя сам код
модели/вьюхи.

Подключение обработчика (receiver)

from django.db.models.signals import post_save
from django.dispatch import receiver
from .models import Profile, User

@receiver(post_save, sender=User)
def create_user_profile(sender, instance, created, **kwargs):
    if created:
        Profile.objects.create(user=instance)

# то же самое без декоратора:
def my_handler(sender, **kwargs):
    ...
post_save.connect(my_handler, sender=User, dispatch_uid='uniq')

dispatch_uid — уникальный id, чтобы обработчик не навесился дважды
(например, при повторном импорте модуля).

Общие сигналы моделей (django.db.models.signals)

  • pre_save: sender, instance, raw, using, update_fields
  • post_save: sender, instance, created, raw, using, update_fields
  • pre_delete / post_delete: sender, instance, using
  • m2m_changed: сигнал о изменении ManyToMany (action, pk_set ...)
  • pre_init / post_init: создание экземпляра модели

Особые сигналы действия:
- post_migrate — после manage.py migrate (полезно для наполнения данными)
- request_started / request_finished — на каждый HTTP-запрос
- user_logged_in / user_logged_out / user_login_failed (django.contrib.auth)

from django.contrib.auth.signals import user_logged_in

@receiver(user_logged_in)
def on_login(sender, request, user, **kwargs):
    print("Залогинился:", user)

Малоизвестное, но нужное

  • Обработчик — обычная функция; первым аргументом всегда sender.
  • kwargs дополнительно: в общем виде **kwargs обязателен.
  • sender=None (не указан) — ловить сигналы ВСЕХ моделей (осторожно!).

Пишем свой сигнал

# app/signals.py
from django.dispatch import Signal

order_ready = Signal()          # наш сигнал без sender-ограничений
# или с передачей данных:
vacancy_updated = Signal()      # отправим instance_close через kwargs

# место отправки (например, в view):
from .signals import order_ready

order_ready.send(sender=Order, order=order, total=order.total)

# приём:
from django.dispatch import receiver

@receiver(order_ready, sender=Order)
def notify_telegram(sender, order, total, **kwargs):
    ...  # отправить уведомление

Где регистрировать обработчики

Модуль приложения app/signals.py, а подключение — в apps.py:

# app/apps.py
from django.apps import AppConfig

class AppConfig(AppConfig):
    name = 'app'

    def ready(self):
        import app.signals  # noqa: F401  — зарегистрировать обработчики

Не создавайте обработчики на уровне модуля верхнего уровня — могут не загрузиться.
ready() вызывается при старте приложения после загрузки всех моделей.

Отключение сигнала

post_save.disconnect(create_user_profile, sender=User)
# или в тестах: patch.object(...)/ блокировка через dispatch_uid
