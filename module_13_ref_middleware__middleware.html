Middleware

Middleware — pluggable-слой между сервером и view. Каждый мидлвер
обрабатывает запрос ДО view и/или ответ ПОСЛЕ view.

Порядок выполнения

  • Запрос идёт по списку MIDDLEWARE СВЕРХУ ВНИЗ (первый видит запрос первым).
  • Ответ идёт СНИЗУ ВВЕРХ (обратный порядок).
MIDDLEWARE = [
    'django.middleware.security.SecurityMiddleware',        # 1. запрос
    'django.contrib.sessions.middleware.SessionMiddleware',
    'django.middleware.common.CommonMiddleware',
    'django.middleware.csrf.CsrfViewMiddleware',            # ...
    'django.contrib.auth.middleware.AuthenticationMiddleware',
    'django.contrib.messages.middleware.MessageMiddleware',
    'django.middleware.clickjacking.XFrameOptionsMiddleware', # последний (первым получает ответ)
]

Хуки в классе мидлвера (классический стиль)

Порядок вызова хуков для одного мидлвера:
process_request → process_view → (view) → process_template_response /
process_response; process_exception при ошибке в view.

class SimpleMiddleware:
    def __init__(self, get_response):
        self.get_response = get_response
        # один раз при старте

    def __call__(self, request):
        # ДО view
        response = self.get_response(request)
        # ПОСЛЕ view (и после process_template_response)
        response['X-My-Header'] = 'добавлено'
        return response

Пример полного набора методов:

class LogMiddleware:
    def __init__(self, get_response):
        self.get_response = get_response

    def process_request(self, request):        # до маршрутизации
        request.started = time.time()
        return None                            # None = идём дальше

    def process_view(self, request, view_func, view_args, view_kwargs):
        return None                            # None = вызывается view

    def process_template_response(self, request, response):
        # у ответа есть render() — TemplateResponse
        response.context_data['now'] = request.started
        return response

    def process_exception(self, request, exception):
        # вернуть None = прокинуть, вернуть Response = перехватить
        return None

    def process_response(self, request, response):
        response['X-Log'] = 'ok'
        return response

Важно: если процесс (request/response) возвращает None — обработка идёт дальше;
чтобы прервать, нужно вернуть HttpResponse.

Современный стиль на middlewares

def my_middleware(get_response):
    # инициализация один раз
    def middleware(request):
        # до view
        response = get_response(request)
        # после view
        return response
    return middleware

Подключение — строка 'myapp.middleware.my_middleware' в MIDDLEWARE.

MiddlewareMixin (удобно для переноса старых процесс-методов)

from django.utils.deprecation import MiddlewareMixin

class MyMixin(MiddlewareMixin):
    def process_request(self, request):
        return None

Что можно делать в мидлвере

  • проверить/ограничить доступ: вернуть HttpResponseForbidden в process_request;
  • добавить данные в request (request.user, request.session);
  • изменить исходящий response (заголовки, сжатие);
  • перехватить исключение и отдать свою страницу (process_exception).
