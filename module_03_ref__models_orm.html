Модели и ORM (осправочник)

Поля моделей (часто используемые)

ПолеНазначение
-----------------
CharField(max_length=N)строка (текст) фикс. длины
TextField()длинный текст
IntegerField()целое число
FloatField()число с плавающей точкой
BooleanField()True/False
DateTimeField()дата и время
DateField()дата
ForeignKey(Модель, on_delete=...)связь многие-к-одному
ManyToManyField(Модель)связь многие-ко-многим
OneToOneField(Модель)связь один-к-одному

on_delete (что делать при удалении родителя)

  • CASCADE — удалить зависимые записи (часто)
  • SET_NULL — поставить NULL (нужно null=True)
  • PROTECT — запретить удаление, если есть зависимые
  • DO_NOTHING — ничего не делать

Метаданные и __str__

class Author(models.Model):
    name = models.CharField(max_length=100)

    class Meta:
        ordering = ["name"]       # сортировка по умолчанию

    def __str__(self):
        return self.name

CRUD через ORM

Создать

b = Book(title="Война и мир", author=author_obj)
b.save()
# или
b = Book.objects.create(title="...", author=author_obj)

Прочитать (выборка)

Book.objects.all()                        # все
Book.objects.get(id=1)                    # один (ошибка если нет/несколько)
Book.objects.filter(author=author_obj)    # фильтр
Book.objects.exclude(title="...")         # исключить
Book.objects.order_by("-id")[:10]         # сортировка (-" — убывание), лимит
Book.objects.get_or_create(...)           # получить или создать

Обновить

b.title = "Новое название"
b.save()
# массово:
Book.objects.filter(...).update(pages=10)

Удалить

b.delete()
Book.objects.filter(...).delete()

Связанные объекты

choice_set.all()      # обратная связь ForeignKey: q.choice_set.all()
question.author       # прямая связь
question.author_set   # обратная (ManyToMany) — convention _set

Агрегации (через expressions)

from django.db.models import Count, Sum, Avg, Max
Book.objects.aggregate(total=Sum("pages"), avg=Avg("pages"))
Author.objects.annotate(num_books=Count("book"))

Q-объекты (сложные условия)

from django.db.models import Q
Book.objects.filter(Q(title__icontains="война") | Q(pages__gt=500))

ForeignKey: related_name

class Book(models.Model):
    author = models.ForeignKey(Author, on_delete=models.CASCADE,
                               related_name="books")
# тогда обратная связь: author.books.all()
