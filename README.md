# django-guide

Учебник и справочник по Django на русском языке — с нуля до публикации своего сайта.

- **Сайт:** https://kilmanr.github.io/django-guide/
- **Источник материала:** docs.djangoproject.com, Django Girls, MDN (адаптировано и переведено на русский)

## Состав репозитория

| Раздел | Что внутри |
|--------|-----------|
| **Шпаргалка** | Команды Django «на кончиках пальцев»: создание проекта, manage.py, модели, миграции, shell |
| **Документация** | Справочники: Модели и ORM · Views/URLconf/Templates/Forms · Admin/Settings/Deploy · Docker для Django |
| **Туториал: Django (официальный)** | 7 частей — от «запросов и ответов» до кастомизации админки |
| **Туториал: Django Girls** | 23 главы на русском: установка, Python, Django, модели, шаблоны, публикация |
| **Туториал: MDN Mozilla Developer** | 14 частей: полный проект «сайт местной библиотеки» до безопасности и деплоя |

## Как собран сайт

Исходный контент — Markdown (out/**/*.md), собирается в HTML скриптом
scripts/md2html.py с локальным шрифтом Noto Sans (woff2) и адаптивным CSS.
Публикуется на GitHub Pages из ветки gh-pages.
