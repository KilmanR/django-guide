Часть 3: Представления и шаблоны

Теперь вернём данные из БД в HTML через шаблон.

Создаём шаблон

Файл polls/templates/polls/index.html:
``html<br>{% if latest_question_list %}<br> <ul><br> {% for question in latest_question_list %}<br> <li><a href="/polls/{{ question.id }}/">{{ question.question_text }}</a></li><br> {% endfor %}<br> </ul><br>{% else %}<br> <p>Нет голосований.</p><br>{% endif %}<br>``

Обновляем view

polls/views.py:
```python
from django.shortcuts import render
from .models import Question

def index(request):
latest_question_list = Question.objects.order_by("-pub_date")[:5]
context = {"latest_question_list": latest_question_list}
return render(request, "polls/index.html", context)
```

Подключаем детальную страницу

Добавьте в polls/urls.py:
``python<br>path("<int:question_id>/", views.detail, name="detail"),<br>`<br>и в views.py:<br>``python
from django.http import Http404

def detail(request, question_id):
try:
question = Question.objects.get(pk=question_id)
except Question.DoesNotExist:
raise Http404("Вопрос не существует")
return render(request, "polls/detail.html", {"question": question})
```
