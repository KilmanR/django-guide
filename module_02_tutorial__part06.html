Часть 6: Статика (CSS, картинки, JS)

Создаём CSS

Файл polls/static/polls/style.css:
``css<br>body { background: white; color: #333; font-family: sans-serif; }<br>``

Подключаем в шаблон

В начале polls/templates/polls/index.html:
``html<br>{% load static %}<br><link rel="stylesheet" href="{% static 'polls/style.css' %}"><br>``

Настройки (dev)

В settings.py уже есть STATIC_URL = "static/". Это путь на сервере.
Django сам находит статику в static/ внутри приложений.

В проде (collectstatic)

python manage.py collectstatic

собирает всё из приложений в одну папку STATIC_ROOT.
