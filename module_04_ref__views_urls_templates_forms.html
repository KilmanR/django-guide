Views, URLconf, Templates, Forms (справочник)

View (представление) — функция

from django.http import HttpResponse, JsonResponse, Http404
from django.shortcuts import render, redirect, get_object_or_404

def index(request):
    return HttpResponse("Привет")

def page(request):
    return render(request, "app/page.html", {"title": "Моя"})

def obj(request, pk):
    model = get_object_or_404(MyModel, pk=pk)
    return render(request, "app/obj.html", {"obj": model})

def json_view(request):
    data = {"status": "ok"}
    return JsonResponse(data)

def redir(request):
    return redirect("app:index")

Generic Class-Based Views (краткие)

from django.views import generic
from .models import Book

class BookList(generic.ListView):
    model = Book
    template_name = "app/book_list.html"

class BookDetail(generic.DetailView):
    model = Book
    template_name = "app/book_detail.html"

URLconf (urls.py)

from django.urls import path, re_path
from . import views

app_name = "app"
urlpatterns = [
    path("", views.index, name="index"),
    path("books/", views.book_list, name="book_list"),
    path("books/<int:pk>/", views.book_detail, name="book_detail"),
    path("search/", views.search, name="search"),
]

Конвертеры path

<int:...>   целое число
<str:...>   строка
<slug:...>  slug (буквы-цифры и "-")
<uuid:...>  UUID
<path:...>  путь (включая слэши)

Namespace в шаблонах

{% url 'app:book_detail' book.id %}

Templates (шаблоны) — базовые теги

{{ variable }}
{% if %} {% else %} {% endif %}
{% for item in list %} ... {% endfor %}
{% url 'name' arg1 %}
{% include "partial.html" %}
{% extends "base.html" %}
{% block content %} ... {% endblock %}
{% load static %}<img src="{% static 'img/a.png' %}">

Наследование шаблонов

base.html:

<!DOCTYPE html>
<html><body>
{% block content %}{% endblock %}
</body></html>

дочерний:

{% extends "base.html" %}
{% block content %}<h1>Мой контент</h1>{% endblock %}

Forms (Формы)

from django import forms

class ContactForm(forms.Form):
    name = forms.CharField(max_length=100)
    email = forms.EmailField()
    message = forms.CharField(widget=forms.Textarea)

def contact(request):
    if request.method == "POST":
        form = ContactForm(request.POST)
        if form.is_valid():
            # обработать form.cleaned_data
            return redirect("success")
    else:
        form = ContactForm()
    return render(request, "app/contact.html", {"form": form})

ModelForm (формы от моделей)

from django import forms
from .models import Book

class BookForm(forms.ModelForm):
    class Meta:
        model = Book
        fields = ["title", "author", "pages"]

CSRF

В любой POST-форме в шаблоне обязателен:

{% csrf_token %}

Безопасность

  • Всегда валидируйте вход от пользователя (is_valid()).
  • Используйте ORM-фильтры (а не raw SQL) — защита от injection.
  • В формах доверяйте cleaned_data, а не request.POST напрямую.
