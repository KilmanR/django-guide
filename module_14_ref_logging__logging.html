Логирование (Logging)

Django использует стандартный модуль logging из Python. Всё настраивается
в переменной LOGGING в settings.py (dictConfig).

Уровни логирования

DEBUG < INFO < WARNING < ERROR < CRITICAL
Запись попадает в лог только если её уровень >= порога хендлера.

Быстрый старт: простой LOGGING в settings.py

import os

LOGGING = {
    'version': 1,
    'disable_existing_loggers': False,
    'formatters': {
        'simple': {
            'format': '{asctime} {levelname} {name}: {message}',
            'style': '{',
        },
    },
    'handlers': {
        'console': {
            'class': 'logging.StreamHandler',
            'formatter': 'simple',
        },
        'file': {
            'class': 'logging.FileHandler',
            'filename': os.path.join(BASE_DIR, 'logs/app.log'),
            'formatter': 'simple',
            'encoding': 'utf-8',
        },
    },
    'loggers': {
        'django': {
            'handlers': ['console', 'file'],
            'level': 'INFO',
            'propagate': False,
        },
        'myapp': {              # логгер вашего приложения
            'handlers': ['console', 'file'],
            'level': 'DEBUG',
            'propagate': False,
        },
    },
}

Логирование в коде

import logging

logger = logging.getLogger(__name__)   # имя = 'app.views'

logger.debug('отладочное')
logger.info('запрос %s обработан', request.path)
logger.warning('что-то подозрительное')
logger.error('упало: %s', exc_info=True)   # exc_info — трейсбек
logger.critical('критично')

Параметры в сообщение — через %s (не f-string), чтобы не считать, пока не надо.

Кастомный хендлер-фильтр

LOGGING = {
    ...
    'filters': {
        'require_debug_false': {
            'class': 'django.utils.log.RequireDebugFalse',
        },
    },
    'handlers': {
        'mail_admins': {
            'level': 'ERROR',
            'class': 'django.utils.log.AdminEmailHandler',
            'filters': ['require_debug_false'],   # только не в DEBUG
        },
    },
}

Встроенные логгеры Django

  • django — основа, посылает в него всё логирование.
  • django.request — каждый HTTP-запрос (уровень 4xx-5xx).
  • django.db.backends — SQL-запросы (в DEBUG пишет все).
  • django.security — SecurityDisallowed/другие предупреждения безопасности.
  • django.server — логи сервера runserver (в dev).
  • django.template, django.contrib.auth...

Шаблон форматирования (style '{')

{asctime}   время записи
{levelname} уровень
{name}      имя логгера (модуль)
{message}   само сообщение
{lineno}    номер строки
{funcName}  имя функции

Для JSON-логов ловко подойдёт 'format': '{"t": "{asctime}", "l": "{levelname}", "m": "{message}"}'.

Логирование в tests

python -Wall manage.py test    # показать все warning-и
# или в тестах assertLogs:
with self.assertLogs('myapp', level='INFO') as cm:
    do_action()
    self.assertIn('запрос обработан', cm.output[0])
