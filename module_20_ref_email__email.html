Отправка email

Настройка в settings.py

# backend (куда именно слать):
EMAIL_BACKEND = 'django.core.mail.backends.smtp.EmailBackend'   # реальная рассылка
EMAIL_HOST = 'smtp.yandex.ru'          # или smtp.gmail.com
EMAIL_PORT = 465                       # 465 SSL / 587 STARTTLS
EMAIL_USE_SSL = True                   # для 465
# EMAIL_USE_TLS = True                 # для 587
EMAIL_HOST_USER = 'noreply@example.ru'
EMAIL_HOST_PASSWORD = 'пароль-приложения'

DEFAULT_FROM_EMAIL = 'noreply@example.ru'   # от кого по умолчанию
SERVER_EMAIL = 'noreply@example.ru'

Тестовые бэкенды (ничего не отправляют):

EMAIL_BACKEND = 'django.core.mail.backends.console.EmailBackend'  # в консоль
EMAIL_BACKEND = 'django.core.mail.backends.locmem.EmailBackend'   # для тестов — mail.outbox
EMAIL_BACKEND = 'django.core.mail.backends.filebased.EmailBackend' # в файлы
EMAIL_FILE_PATH = os.path.join(BASE_DIR, '_emails')

send_mail — быстро и просто

from django.core.mail import send_mail

send_mail(
    subject='Добро пожаловать!',          # тема
    message='Спасибо за регистрацию.',    # текст
    from_email=None,                      # = DEFAULT_FROM_EMAIL
    recipient_list=['user@example.ru'],
    fail_silently=False,                  # True — не кидать ошибки
)

С HTML:

send_mail(
    'Акция!', 'Текстовая версия',
    'noreply@example.ru', ['user@example.ru'],
    html_message='<strong>Акция!</strong> промокод CODE10',
)

send_mail возвращает количество доставленных писем (0/1 и т.д.).

EmailMessage — полный контроль (вложения, заголовки)

from django.core.mail import EmailMessage

email = EmailMessage(
    subject='Отчёт',
    body='Во вложении.',
    from_email='noreply@example.ru',
    to=['boss@example.ru'],
    # bcc=['admin@example.ru'], reply_to=...
    headers={'Message-ID': '123', 'X-Custom': '1'},
)
email.attach_file('/path/file.pdf')                       # по пути
email.attach('name.txt', b'данные как bytes', 'text/plain')  # вручную
email.send(fail_silently=False)

EmailMultiAlternatives — text + html одной рассылкой:

from django.core.mail import EmailMultiAlternatives

msg = EmailMultiAlternatives('Тема', 'текст', None, ['user@x.ru'])
msg.attach_alternative('<h1>HTML</h1>', 'text/html')
msg.send()

Тестирование почты

from django.core import mail
from django.test import TestCase

class MailTest(TestCase):
    def test_send(self):
        with self.settings(EMAIL_BACKEND='django.core.mail.backends.locmem.EmailBackend'):
            send_mail('привет', 'текст', None, ['a@b.ru'])
            self.assertEqual(len(mail.outbox), 1)
            m = mail.outbox[0]
            self.assertEqual(m.subject, 'привет')
            self.assertIn('текст', m.body)
  • в консоль-бэкенде письма печатаются в stdout — удобно в dev.
  • для проверки вручную: python manage.py shell + send_mail.
  • Реальные сервисы: Яндекс/Google требуют «пароли приложения» (не основной).

Ошибки

  • SMTPServerDisconnected, SMTPAuthenticationError — проверьте порт, SSL/TLS,

пароль-приложение.
- SocketTimeoutError — SMTP-сервер не отвечает; не ставьте fail_silently=True
молча — логируйте.
