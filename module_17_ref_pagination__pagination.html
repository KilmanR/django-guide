Пагинация (Pagination)

Разбиение большого списка на страницы.

Пагинация вручную (функция-вьюха)

from django.core.paginator import Paginator
from django.shortcuts import render
from .models import Article

def article_list(request):
    articles = Article.objects.all().order_by('-created_at')
    paginator = Paginator(articles, 10)              # по 10 на странице
    page_number = request.GET.get('page')            # ?page=2
    page_obj = paginator.get_page(page_number)       # безопасно: лишнее → последняя
    return render(request, 'app/list.html', {'page_obj': page_obj})

get_page() сам ловит PageNotAnInteger и EmptyPage (в отличие от page()).

Ключевые свойства

page = paginator.get_page(n)
page.object_list        # объекты текущей страницы
page.has_next()         # есть ли следующая
page.has_previous()
page.next_page_number()
page.previous_page_number()
page.paginator.num_pages     # всего страниц
page.paginator.page_range    # range(1, num_pages+1)
page.number
page.paginator.count         # всего объектов
page.start_index()           # индекс первого элемента на странице (1..count)
page.end_index()

Шаблон

{% for article in page_obj %}
    <h3>{{ article.title }}</h3>
{% endfor %}

<div class="pagination">
    {% if page_obj.has_previous %}
        <a href="?page={{ page_obj.previous_page_number }}">&laquo;</a>
    {% endif %}

    <span>Страница {{ page_obj.number }} из {{ page_obj.paginator.num_pages }}</span>

    {% if page_obj.has_next %}
        <a href="?page={{ page_obj.next_page_number }}">&raquo;</a>
    {% endif %}
</div>

<!-- номера страниц -->
{% for num in page_obj.paginator.page_range %}
    <a href="?page={{ num }}"
        {% if num == page_obj.number %} class="active" {% endif %}>{{ num }}</a>
{% endfor %}

Пагинация + QuerySet не по-странице (Count)

Если нужен только подсчёт и 1 страница — игнорируйте, пагинатор и так считает
count() только когда нужно (ленивый).

CBV ListView с пагинацией

from django.views.generic import ListView

class ArticleListView(ListView):
    model = Article
    template_name = 'app/list.html'
    context_object_name = 'articles'
    paginate_by = 10                     # включая пагинацию
  • в шаблоне доступны object_list, paginator, page_obj, is_paginated.
  • для «умных» ссылок с сохранением фильтров собирайте QueryDict:
# в шаблоне
{% if page_obj.has_previous %}
<a href="?{{ request.GET.urlencode }}&page={{ page_obj.previous_page_number }}">назад</a>
{% endif %}

Кастомная разбивка (по датам, group)

paginator = Paginator(articles, 10, orphans=2)   # 2 «сироты» хвоста - тоже страница
if n > paginator.num_pages:                      # ручная защита
    n = paginator.num_pages

Ошибки пагинации

  • PageNotAnInteger — «page» не число.
  • EmptyPage — страницы не существует (get_page вернёт последнюю).

Используйте get_page() — он обрабатывает все исключения сам.
