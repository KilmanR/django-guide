Что делать дальше?

Сделай перерыв и расслабься. Ты только что закончила огромную работу.

И не забудь подписаться на страничку Django Girls в Facebook и Twitter, чтобы оставаться в курсе новостей.

Можем ли мы посоветовать дополнительные ресурсы для обучения?

Конечно! Сейчас доступно _огромное_ количество ресурсов для изучения всевозможных навыков программирования. Мы поможем подобрать тебе то, что будет полезно изучить на следующем этапе. Вот несколько бесплатных ресурсов (или ресурсов с большим количеством бесплатного контента):

Django

  • Другое наше руководство, Django Girls Tutorial: Extensions
  • Django's official tutorial
  • Getting Started With Django video lessons

HTML, CSS и JavaScript

  • Codecademy's web development course
  • freeCodeCamp

Python

  • Codecademy's Python course
  • Google's Python course
  • Learn Python The Hard Way book – несколько первых упражнений бесплатно
  • New Coder tutorials – многообразие практических примеров того, как ты можешь использовать Python
  • edX – большинство курсов бесплатны, но если вам нужен сертификат, необходимо оплатить
  • Coursera's Python specialization – некоторые видеокурсы можно изучать бесплатно, также можешь получить сертификат Coursera после успешного прохождения
  • Python for Everybody

Работа с данными

  • Codecademy's data science course
  • edX – большинство курсов бесплатны, но если вам нужен сертификат, необходимо оплатить
  • Dataquest первые 30 "миссий" бесплатно

Нам уже не терпится узнать, что ты создашь следующим!
