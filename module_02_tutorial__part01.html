Часть 1: Запросы и ответы

Проект создан. Теперь сделаем первую страницу («привет, django»).

Создание приложения

python manage.py startapp polls

Папка polls/ появляется рядом с mysite/.

Регистрация приложения

В mysite/settings.py → INSTALLED_APPS добавить 'polls'.

Первый view (представление)

В polls/views.py:

from django.http import HttpResponse

def index(request):
    return HttpResponse("Hello, world. Вы в опросе.")

URL для главной страницы

В polls/urls.py (создайте файл):

from django.urls import path
from . import views

urlpatterns = [
    path("", views.index, name="index"),
]

Подключить к проекту

В mysite/urls.py:

from django.contrib import admin
from django.urls import include, path

urlpatterns = [
    path("polls/", include("polls.urls")),
    path("admin/", admin.site.urls),
]

Запустите python manage.py runserver и перейдите на http://127.0.0.1:8000/polls/
— увидите «Hello, world.». Это и есть запрос-ответ.
