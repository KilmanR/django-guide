Форма голосования

В шаблоне polls/detail.html:
``html<br><form action="{% url 'polls:vote' question.id %}" method="post"><br>{% csrf_token %}<br>{% for choice in question.choice_set.all %}<br> <input type="radio" name="choice" id="choice{{ forloop.counter }}"<br> value="{{ choice.id }}"><br> <label for="choice{{ forloop.counter }}">{{ choice.choice_text }}</label><br><br>{% endfor %}<br><input type="submit" value="Голосовать"><br></form><br>``

View для голосования

polls/views.py:
```python
from django.shortcuts import get_object_or_404, render
from django.http import HttpResponseRedirect
from django.urls import reverse

def vote(request, question_id):
question = get_object_or_404(Question, pk=question_id)
try:
selected = question.choice_set.get(pk=request.POST["choice"])
except (KeyError, Choice.DoesNotExist):
return render(request, "polls/detail.html", {
"question": question,
"error_message": "Вы ничего не выбрали.",
})
selected.votes += 1
selected.save()
return HttpResponseRedirect(reverse("polls:results", args=(question.id,)))
```

Паттерны URL с namespace

В mysite/urls.py замените include на:
``python<br>path("polls/", include("polls.urls")),<br>`<br>а в polls/urls.py задайте:<br>`python<br>app_name = "polls"<br>urlpatterns = [ ... имя путь с name="vote", "results" ... ]<br>`<br>Тогда в шаблоне используйте {% url 'polls:vote' %}`.
